Tests : `check-erreurs-github.js`, mutations sur les neuf fonctions ajoutées/modifiées.
- **Cloisonnement par profil** : toute donnée d'usager passe par `ess-<profil>-…` (`pk`/`pkFor`) ; migration ou archivage ne touche jamais un autre profil. Toute migration délicate mérite un test (une migration non testée a réduit 11 CMS à 6).
